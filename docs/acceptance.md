# MVP 设备验收

## 已运行的验证

- 原生 SwiftUI / PhotoKit / AVFoundation 源码通过 iOS Simulator SDK 编译和链接。
- 20 项核心逻辑 XCTest 在 macOS 与 iPhone 17 模拟器中通过，包含一万项媒体索引、手势主方向判定、返回不取消标记及时间分组定位。
- 已安装 iOS 运行时，完整 Xcode App 构建通过，在 iPhone 17 模拟器上成功安装与启动演示模式。

## 在设备或安装运行时后验收

使用可恢复的测试照片与视频进行以下检查：

1. 首次启动、拒绝权限、从设置返回、仅授权部分照片；有限权限管理后应保留仍可访问的待清理项。
2. 空相册显示提示；全部、照片、视频过滤准确，照片包含 Live Photo；切换过滤时待清理计数保持。
3. 左滑标记并自动进入下一张；上滑仅下一张；下滑返回上一张且保留标记；轻点媒体不标记。右滑和小位移不处理，斜向手势按主方向判断。首张不能后退，末尾仍可下滑回看；显式撤销恢复操作前状态，连续快速操作不误作用于另一张。
   长按 0.5 秒后，动画中心应在按压点，然后定位当前媒体的相册时间位置并高亮；松手不触发标记或翻页。用不同按压点复验。在时间网格中查看相邻照片/视频，返回随机流保持原位置；有限权限仅展示可访问媒体，开启「减少动态效果」时弱化动画。
4. Live Photo 停留后播放，视频静音循环，进度和声音开关正常；打开清理页或进入后台时停止视频播放。
5. 结算页显示四列缩略图；点击取消单个标记，长按预览不取消标记，预览的「保留这张」会取消标记。
6. 「暂不清理，全部保留」清空本次标记；再次撤销不能重新引入已结算的标记。
7. 原生删除触发系统确认；系统取消时清理页和标记保持；成功后仅所选媒体进入「最近删除」。
8. iCloud 未下载媒体显示离线提示，空间估算提示缺失数据；断网下浏览本地图片、视频和清理仍可使用。
9. 指定相册范围正确；已存在标记时切换相册要求先结算或全部保留，不悄悄丢失标记。
10. 在 Photos 中新增、删除媒体后返回 App，仍可访问的当前回忆保持，新增媒体加入后续顺序。
11. 长时间浏览大相册，通过 Instruments 检查内存、帧率、预缓存、取消请求和资源计量的开销；60/120 fps 需实机测量。
12. 用 VoiceOver 操作当前回忆、撤销、保留、清理清单和大图预览；在小屏 iPhone 和 iPad 检查布局。

演示模式 `-demo` 可验证界面及基础标记流程，不代替真实 PhotoKit 权限、动态媒体或删除验收。
