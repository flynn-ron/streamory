## 一、 产品概述与定位

### 1.1 产品简介
* **产品名称**：影流
* **产品英文名**：Streamory
* **产品定位**：一款轻松、舒缓的沉浸式历史照片与视频随机回顾工具，帮助用户在怀旧与放松的浏览过程中“随手做清理”。
* **核心理念**：“解压/怀旧为主，清理为辅”。打破传统相册清理工具强烈的“工作感”与“焦虑感”。

### 1.2 目标用户
* 手机相册积攒上万张照片/视频、存储空间频频告急的 iOS 用户。
* 缺乏专门时间与耐心按时间轴逐张清理相册，但喜爱回顾旧记忆的用户。

### 1.3 核心差异化卖点 (USP)
* **加权随机流 (Random Stream)**：打破传统时间轴顺序，提供刷短视频般的画廊沉浸感与随机惊喜。
* **延迟决策机制**：浏览时不立即弹窗删除，仅做标记；浏览结束时在结算页一次性二次确认，极大地降低心理负担与误删风险。

## 二、 用户流程 (User Flow)

```
[ 打开 App ]
     │
[ 权限请求 / 索引加载 ] ─── (获取 PhotoKit 读写权限)
     │
[ 进入“随机流”主界面 ]
     │
     ├─► [ 左滑 ] ───► 标记为“待清理” ──► 右上角计数器 +1 ──► 自动下一张
     ├─► [ 上滑 ] ───► 保持/不标记 ─────────────────────► 自动下一张
     ├─► [ 下滑 ] ───► 返回上一张，保留原有标记
     ├─► [ 长按照片 ] ───► 触点穿越动画 ───► 当前照片在相册中的时间位置
     └─► [ 点击“撤销” ]  ───► 取消上一张标记 ───────────────────► 恢复状态
     │
[ 点击顶部“完成/退出”或“已标记 X 项” ]
     │
[ 弹出半屏/全屏结算 Sheet ] ──► 展示已标记缩略图 & 预计释放存储空间
     │
     ├─► [ 单击缩略图 / 点击✕ ] ──► 取消个别照片标记 (安全保留)
     ├─► [ 点击“暂不清理” ]     ──► 清空本次标记，返回主界面
     └─► [ 点击“确认移入系统废纸篓” ]
               │
          [ 调用 iOS PhotoKit 原生 API ] ──► 弹出系统二次确认 ──► 执行物理删除 (进入系统废纸篓)
```

## 四、 UI/UX 设计规范 (UI/UX Design Specifications)

### 4.1 视觉与主题系统
* **视觉风格**：沉浸式极简暗黑风（Dark Immersive UI）。
* **色盘规范**：
  * **主背景色**：`#000000`（纯黑，适配 OLED，无边界感）
  * **卡片底色/次背景**：`#121212` / `#1C1C1E`
  * **删除/标记色**：警告红 `#FF3B30`（带有半透明高光）
  * **保留/主文本色**：`#FFFFFF`
  * **辅助文本色**：`rgba(255, 255, 255, 0.6)`
  * **毛玻璃遮罩**：`UIBlurEffect.Style.systemUltraThinMaterialDark`

### 4.2 触觉反馈 (Haptics)
* **翻页切换**：轻微无感微震（`UIImpactFeedbackStyle.light`）。
* **标记删除**：中等沉重落感（`UIImpactFeedbackStyle.medium`）。
* **最终确认删除**：连击成功震动（`UINotificationFeedbackType.success`）。

### 4.3 核心界面布局设计

#### A. 主浏览界面 (Stream Viewer)
* **全屏无边框**：照片自适应屏幕，两侧空白由模糊背景填充。
* **顶部悬浮导航**：
  * 左侧：`完成/退出` 按钮。
  * 中间：模式切换胶囊（`全部` | `图片` | `视频`）。
  * 右侧：待清理计数器（如 `已标记 3 项`）。
* **底部信息与操作区**：
  * 悬浮显示半透明日期与地点。
  * 左下角悬浮 `↩ 撤销` 按钮。
  * 提示：`上滑下一张 · 下滑上一张 · 长按回到过去`。
* 底部中央居中放置 `🗑️️ 左滑标记` 交互提示区。

#### B. 清理确认弹窗 (Checkout Sheet)
* **半模态弹窗 (Sheet)**：从底部向上滑出，支持下拉手势收起。
* **头部统计区**：
  * 文案：“`本次回顾已标记 X 项媒体`”。
  * 体积高亮：“`预计释放存储空间 XXX MB`”（绿色/高亮字样）。
* **4 列宫格网格 (Grid)**：
  * 显示已标记图片的缩略图，右上角标注红圈 `✕`。
  * 点击任意卡片或 `✕`：卡片淡出，取消标记（安全保留）。
  * 长按卡片：弹出放大预览模式。
* **底部 CTA 操作栏**：
  * 主按钮（高亮红）：`确认移入系统废纸篓 (释放 XXX MB)`。
  * 次按钮（灰底/纯文本）：`暂不清理，全部保留`。

## 五、 非功能性需求与性能指标 (NFRs)

1. **流畅度与预加载**：
   * 后台保持预加载后续 3 张图片/视频帧，确保手势滑动无卡顿，达到 60/120 fps 帧率。
2. **内存控制**：
   * 已滑过的媒体资源需及时从内存中释放，防止长时间滑动导致 App 因内存溢出 (OOM) 闪退。
3. **隐私与离线**：
   * 所有图像分析与数据检索 100% 在本地完成，不需要且不发起任何网络请求。

## 六、 路线图与后续规划 (Roadmap)

* **V1.0 (MVP 阶段)**：
  * 基础随机流展示（图片/视频分离）。
  * 快捷标记 + 退出时的二次确认批量删除。
  * 释放空间统计。
* **V1.1 (体验与氛围升华)**：
  * 加入环境白噪音背景音（如雨声、篝火声、舒缓轻音乐），增强“解压”体验。
  * 引入“历史上的今天”记忆引擎。
* **V1.2 (本地 AI 辅助)**：
  * 集成 iOS 本地 Vision 框架，自动高亮连拍、模糊、截图等低质图片供快速标记。
